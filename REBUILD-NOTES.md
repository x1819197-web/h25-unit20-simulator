# UNIT-20 v3.0 — результаты переделки

Дата: 19.10.2026. Исходный commit: `cd33290fe0189f0a9931b81f0bd8a1aab94f3c4b`.
Рабочая ветка: `rebuild/native-hmi`. Изменения сделаны локально, не отправлены на GitHub.

## Основное изменение

Полноэкранные фотографии исходной SCADA удалены из рабочего интерфейса. H25 и KU теперь используют HTML/SVG с одной отрисовкой каждого элемента. Нет растровых кнопок под настоящими кнопками, масок для закрашивания старых значений, захваченных таскбаров и статических чисел на фоне.

Это новая адаптивная компоновка в SCADA-стиле, **не точная векторная перерисовка каждого пикселя оригинальных мнемосхем**. Для инженерной 1:1-копии все трубопроводы/арматуру необходимо сверить с P&ID/OEM-документацией. Иллюстративные SVG здесь отображают основные процессы, а не заменяют чертежи оборудования.

## Результаты запуска

- `npm test`: 33 + 26 = **59 PASS**, 0 FAIL.
- `npm run build`: генерирует H25 + KU; изображений в output нет.
- `npm run test:browser`: **308 экранных проверок, 28 layout-конфигураций, 9 UI-сценариев**, 0 runtime raster requests, 0 пойманных pageerror.
- Проверены source и deploy обоих модулей.
- Проверен реальный межоконный BroadcastChannel/localStorage обмен с передачей trip котла в модель H25.
- Проверена компиляция Python-launcher (`py_compile`), но не GUI Windows.

Автотесты не являются доказательством отсутствия всех ошибок. Физические уставки, интерфейс на целевых ОС/мониторах и рабочие сценарии оператора требуют приёмки.

## Перед выпуском для обучения

1. Сверить рабочие диапазоны/единицы всех REF-каналов и решить, какие должны стать динамическими.
2. Подтвердить OEM-последовательности, permissives и защиты.
3. Если нужен точный оригинальный HMI — закончить инженерную перерисовку по экранной инвентаризации/P&ID, не возвращая фото-подложки.
4. Принять модель котла и сети; при необходимости заменить reduced-order уравнения и saturation table.
5. Провести ручную проверку Windows/WebView2/DPI, fullscreen, звука и двух видимых окон.
