# H25 UNIT-20 — рабочая навигация и управление

Откройте **standalone.html** в браузере: всё встроено, сеть и установка программ не нужны. Для исходников через HTTP можно открыть `index.html`.

## Что исправлено

- В одном приложении открываются все 19 технологических экранов и MENU; правая навигация, кнопки меню, история браузера и прямое открытие через `#ffd` / `#sync` работают без загрузки других файлов.
- При переходах сохраняются общие состояние, задания и часы модели. Модель не переинициализируется на каждом экране.
- Согласованный первый кадр START-UP сохранён. Проверка PNG до/после подключения навигации: различающихся пикселей нет.
- START / STOP / MASTER RESET / TRIP, выбор режимов, ввод нагрузки, удержание RAISE/LOWER, управление 16 приводами, возбуждение, синхронизация, IBH release, сброс счётчиков и overspeed test подключены к общей учебной модели.
- Добавлены учебные ручные режимы CRANK → продувка → FIRE → AUTO, с проверкой разрешающих условий. Защиты ядра не обходятся.
- Команда, которую запрещает текущий режим или защита, выдаёт видимую причину. Сообщение не затирается следующим тиком модели.
- Исправлена работа ENTER, CANCEL и подтверждения сброса в защищённом просмотрщике Arena: нативная отправка HTML-форм не требуется.
- Нет фотографий-подложек, растровых изображений или загрузки отвергнутого редизайна.

## Как пользоваться

Начальное состояние — **Base Load**, турбина уже работает. Нажатие START не запускает её повторно: появляется объяснение блокировки. Для нового автоматического пуска: STOP → дождаться остановки (~21 s учебного времени) → AUTO → START. При TRIP сначала дождаться выбега ниже 500 min-1 и выполнить отдельный MASTER RESET.

Прямоугольники **GT Status / FFD Status** — индикаторы, не команды переключения состояния.

Задание нагрузки: нажать белое поле под `Load Set Value`, ввести 0–32 MW, ENTER. RAISE/LOWER требуется удерживать, не только кратко нажимать.

Для ручной учебной последовательности: после остановки выбрать CRANK / START; после 7 s продувки — FIRE / START; AUTO продолжает прогрев и набор скорости. Время намеренно ускорено; это не эксплуатационная инструкция для настоящей турбины.

На MOTORS: AUTO / MANUAL / START / STOP. Установленная в AUTO резервная машина может автоматически подхватить остановленную рабочую машину.

COUNTER RESET запрашивает подтверждение, обнуляет только сбрасываемые счётчики. Пожизненные счётчики сохраняются.

LIFT CALIBRATION открывает учебное окно: перемещение разрешено только при SPEED < 50 min-1 и отсутствии пламени. Это не модель реального исполнительного механизма.

## Границы этой версии

START-UP — согласованная отдельная перерисовка. Остальные страницы подключены и отрисованы native SVG с исходными координатами полей/кнопок; абсолютное визуальное совпадение всех остальных мнемосхем ещё не заявляется. Физика — учебная, не OEM/DCS; LOCAL/REMOTE и COOLDOWN сохраняют положения селекторов, внешняя DCS и отдельный контур охлаждения не реализованы. Часть вспомогательных датчиков остаётся номинальными референсными показаниями.

Полноэкранный режим может быть запрещён политикой встроенного просмотрщика; скачанный HTML следует открыть в отдельной вкладке браузера. Звук включается отдельной кнопкой после пользовательского нажатия.

Опубликованный GitHub Pages этим изменением не заменён.

## F2-4 — уточнение оператора

Подтверждено пользователем: если `FFD < KD4H`, сектор **F2-4** становится белым, не ожидая снижения до KC4L. При `FFD >= KD4H` и разрешённом горении сектор красный. Сравниваются исходные численные значения модели до округления показаний.

- Сектор F2-4 нарисован отдельно от F1/F2-1/F2-2/F2-3: снижение через KD4H не перекрашивает другие сектора.
- Один источник состояния `H25.burnerOpen()` используется на всех страницах с изображением горелки. Команда F2-4 GCV использует ту же текущую уставку KD4H; фактическое положение клапана сохраняет динамику привода.
- При TRIP / отсутствии разрешённого горения все сектора выключены. Красный цвет здесь не заявляется как модель отдельного датчика пламени.
- Поведение остальных ступеней не переопределено по неподтверждённому предположению о KC/KD.
- Проверка: `node exact-startup/test-burner.cjs` — границы 50.8 / 50.799, отсутствие гистерезиса по KC4L, изменение KD4H, 7 страниц, ввод нагрузки обычными кнопками, отключение по TRIP и работа внутри sandbox.

Эта правка не означает завершения переноса всей реальной динамики по присланным PDF: в текущей версии пусковые выдержки ещё учебные ускоренные. График PPE-10-1420 Rev.2 задаёт 12 минут продувки при 1456 min-1 и последующий разгон 10.5% скорости/мин; их перенос, а также полный набор защит из карты уставок 2025 года — отдельная незавершённая часть модели. График сам указывает на необходимость уточнений по результатам испытаний.


## Полный размер окна — v3.1.0

Схема теперь заполняет ширину и высоту доступной области без чёрных полей и без обрезки элементов. SVG использует `preserveAspectRatio="none"`: координаты и порядок элементов прежние, масштаб по X/Y адаптируется к пропорциям окна. Нижняя служебная полоса также серая. При очень отличающихся пропорциях окна формы могут растягиваться — это сознательный режим заполнения, а не обрезка.

`node exact-startup/test-fill.cjs` проверяет заполнение окна на 1917×887, 1366×768, 1280×720, 1024×768 и 390×844.

Сборщик `build.js` ставит эту версию основной по `/` и `/h25/index.html`; старый общий портал сохранён как `/unit20.html`, KU доступен по `/ku/index.html`. Общая телеметрия H25 ↔ KU включена в bundle и проверена двухоконным браузерным тестом.
